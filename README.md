🧠 Концепция
SnakeMaze — это классическая игра «Змейка» с добавлением лабиринта. Управляйте змейкой по полю, где стены образуют препятствия. Собирайте еду, чтобы расти, и старайтесь не врезаться в стены или в себя. Игра становится сложнее с каждым уровнем: скорость растёт, а лабиринт меняется.

✅ Лабиринт — стены генерируются случайным образом или загружаются из уровня.

✅ Управление — стрелки (вверх/вниз/влево/вправо) для направления змейки.

✅ Счёт и рекорд — очки за каждую съеденную еду, лучший результат сохраняется.

✅ Уровни — после определённого количества очков уровень повышается, скорость увеличивается.

✅ Бонусы — иногда появляется золотая еда, дающая больше очков.

✅ Пауза — нажмите P для паузы.

✅ Кроссплатформенность — работает в консоли на Windows, Linux и macOS.

🚀 Как запустить
Каждая версия является консольным приложением. Управление осуществляется клавишами:

↑ ↓ ← → — движение

P — пауза/продолжение

Q — выход (в некоторых версиях)

Для запуска используйте соответствующие команды:

Python
bash
python snake_maze.py
C++
bash
g++ -std=c++17 snake_maze.cpp -o snake_maze -lncurses  # для Linux
# или без ncurses, с использованием conio.h на Windows
./snake_maze
Java
bash
javac SnakeMaze.java && java SnakeMaze
C#
bash
dotnet run
Go
bash
go run snake_maze.go
Rust
bash
cargo run
JavaScript (Node.js)
bash
node snake_maze.js

📦 Содержимое репозитория
Файл	Язык	Особенности
snake_maze.py	Python	неблокирующий ввод (keyboard), генерация лабиринта, рекорд
snake_maze.cpp	C++	conio.h / termios, простая генерация стен, счёт
SnakeMaze.java	Java	Swing-графика (JFrame) для более удобного отображения
SnakeMaze.cs	C#	Console.KeyAvailable, автосохранение рекорда
snake_maze.go	Go	горутины для ввода, генерация лабиринта
snake_maze.rs	Rust	termion, цветной вывод, рекорд в файле
snake_maze.js	JavaScript	keypress, асинхронный ввод, простое отображение
🔮 Расширенные функции
Генерация лабиринта — каждый раз новый, с помощью алгоритма DFS.

Рекорд — сохраняется в файл и отображается при старте.

Бонусная еда — золотая звезда даёт +5 очков, появляется редко.

Анимация — в Java-версии используется Swing для плавного отображения.
